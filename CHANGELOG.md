# Changelog — Icons

Each section below becomes the GitHub release body for that tag (`v<version>` in `NE.Standard.UI.Icons`) and is removed from this file after the release is cut.

## 2.7.0

- **Breaking:** targets `.NET 11` (`net11.0`; building requires the `.NET 11` SDK).
- Updated `material-symbols` to `0.48.3`, adding 11 rounded glyphs (`3 940` total: `ContrastAuto`, `ContrastInverse`, `ContrastInverseAuto`, `Devices2`, `DocumentShareStack`, `InputSearch`, `MailPerson`, `MirrorStack`, `PersonEye`, `PullRequest`, `Speed4Progress`).
- Built on the framework's 2.7.0 release.
